Controls

  • Move — WASD / Arrow keys, or left-click to walk there
  • Use tool / interact — Space, or left-click a nearby tile/animal
  • Select tool — number keys 1–9
  • Tools — Hoe tills, Watering Can waters, Scythe harvests, Seeds plant
  • Pet / collect — act on an animal (collect when it has a product)
  • Talk / quests — act on a villager (look for the ! marker) to accept and turn in quests
  • Buildings — step on the mat below one to enter; leave via the EXIT mat
  • Sleep — face the bed in the house and press E, then confirm (restores energy, next day)
  • Shop — B (buy seeds, sell crops, upgrade tools)
  • Save / Load — K / L (autosaves each new day)
  • New Game — N (erases your save)
  • Help — ? (toggle this screen)
